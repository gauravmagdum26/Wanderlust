# Wanderlust 🌍

A full-stack web application for discovering, managing, and booking travel accommodations. Wanderlust provides a dynamic platform for users to explore global travel destinations and manage their own property listings.

## 🚀 Features

* **User Authentication:** Secure sign-up, log-in, and session management.
* **Listing Management:** Full CRUD (Create, Read, Update, Delete) functionality for property listings.
* **Interactive UI:** Responsive and dynamic user interface for seamless browsing.

## 🛠️ Tech Stack

* **Frontend:** HTML, CSS (Bootstrap)
* **Backend:** Node.js, Express.js
* **Database:** MongoDB
* **Version Control:** Git & GitHub
